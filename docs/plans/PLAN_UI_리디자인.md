# Minion Match UI 리디자인 계획

작성일: 2026-07-12  
상태: 진행 중

## 목표

- 기술 전환이 완료된 게임에 화면별 UI 개선을 단계적으로 적용한다.
- 한복 매치의 명확한 시작 흐름을 미니언 테마에 맞게 재해석한다.
- 기능 변경과 시각 변경을 작은 단위로 나눠 회귀를 검증한다.

## 단계

### 1단계: 닉네임 시작 화면

- 첫 진입 시 전체 화면 시작 페이지를 표시한다.
- 닉네임 등록 전 게임 진입을 차단한다.
- EASY 12장, NORMAL 16장 선택 버튼을 제공한다.
- 이미지 준비 중에는 난이도 버튼을 비활성화한다.
- Hall of Fame은 게임에 들어가지 않고 열 수 있다.
- 등록한 닉네임을 로컬에 기억하고 메뉴 복귀 시 재사용한다.

진행 상태: 2026-07-12 완료.

### 2단계: 플레이 화면 구조 개선

- 게임 헤더, 상태 통계, 보드, 미션 패널의 정보 우선순위를 재정리한다.
- 모바일에서 카드 크기와 세로 공간을 최적화한다.
- 닉네임은 플레이 중 표시 전용으로 전환한다.

진행 상태: 2026-07-12 완료. Mission Panel을 제거하고 전체 폭 보드, 헤더 내 최소 Restart/Menu 동작, 표시 전용 닉네임으로 정리했다.

### 3단계: 결과·리더보드 개선

- 승리, 저장 중, 저장 실패 상태를 명확히 구분한다.
- 리더보드 모달의 포커스 이동과 모바일 표 레이아웃을 개선한다.

진행 상태: 2026-07-12 완료. Mission Complete 결과 모달과 Play Again, Hall of Fame, Back to Menu 흐름을 구현했다.

### 추가 개선: 플레이 반응성과 리더보드 가독성

- 카드 플립 애니메이션을 600ms에서 350ms로 단축한다.
- 정답 판정은 220ms, 오답 복귀는 600ms로 조정한다.
- 리더보드는 상위 7개 행 높이를 기본 노출하고 8위부터 표 내부에서 스크롤한다.
- 메뉴와 게임 결과 화면에서 동일한 리더보드 컴포넌트를 사용한다.

진행 상태: 2026-07-12 완료.

### 추가 개선: 모바일 게임 배경

- 검정에 가까운 기존 배경 `#050a0f`를 미니언 테마와 어울리는 짙은 네이비 그라데이션으로 교체한다.
- 게임 배경은 `#101c2b`에서 `#07111b`로 이어지게 하고 상단에 은은한 블루 광원을 적용한다.
- `html`, `body`, 게임 루트의 배경을 연결해 모바일 오버스크롤 시 검은 여백이 노출되지 않도록 한다.
- iPhone Safari와 모바일 Chrome을 위해 `theme-color`, `viewport-fit=cover`, `100dvh`를 적용한다.
- iOS 홈 화면 실행 시 상태 표시줄이 배경과 자연스럽게 이어지도록 Apple Web App 메타데이터를 구성한다.

진행 상태: 2026-07-12 완료. 테스트 22개, 타입 검사, Next.js 프로덕션 빌드를 통과했다.

### 4단계: 전체 UI 검증

- 데스크톱과 모바일 반응형을 확인한다.
- 키보드 접근, 포커스, ESC 닫기, 배경 클릭을 검증한다.
- build, typecheck, 단위·컴포넌트 테스트를 통과한다.

검증 상태: 리더보드 7행 스크롤 테스트를 포함해 총 22개 테스트와 타입 검사를 통과했다.
