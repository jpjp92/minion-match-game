## 확인된 주요 개선 사항

- 현재 점수 API는 인증과 충분한 입력 검증 없이 점수를 저장한다.
- `App.tsx` 초기 상태에서 `localStorage`를 직접 사용하므로 Next.js 서버 렌더링에 맞게 수정해야 한다.
- 메뉴 복귀 시 타이머가 계속 실행될 수 있다.
- 점수 저장 실패와 로컬 fallback의 일관성 및 중복 제출 처리가 필요하다.
- 리더보드 조회를 난이도별 서버 쿼리로 변경해야 한다.
- 로컬 이미지 대신 GitHub API를 호출하는 의존성을 제거할 수 있다.
- private bucket도 브라우저에 표시된 이미지의 복사를 완전히 방지하지는 못하며, 접근 제한과 URL 만료 수단으로 사용해야 한다.
- 레퍼런스도 클라이언트에서 계산한 점수를 인증 없이 저장하므로 점수 보안 구현의 기반으로 사용하면 안 된다.
- 레퍼런스 이미지가 최대 2560×2560, 약 904KB이므로 Storage 업로드 전에 크기와 형식 정규화가 필요하다.
- Tailwind CDN과 import map을 Next.js 빌드 구성으로 이전해야 한다.
